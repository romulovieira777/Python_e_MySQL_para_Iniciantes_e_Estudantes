# Seção 01 — Python para Iniciantes

Visão geral
-----------
Esta seção reúne exemplos e exercícios básicos para quem está começando em Python. Os arquivos demonstram conceitos fundamentais como saída no terminal, variáveis, concatenação, operadores lógicos, captura de entrada, conversões de tipos, estruturas condicionais e laços de repetição.

Descrição dos arquivos em `Python_Code`
--------------------------------------
- `01_Print.py`  
  Demonstrações básicas de saída no console usando `print()`.

- `02_Variaveis.py`  
  Exemplos de declaração e uso de variáveis (tipos básicos, regras de nomeação).

- `03_Concatenacao.py`  
  Como concatenar strings e formatar saídas.

- `04_Operadores_Logicos.py`  
  Exemplos de operadores lógicos (`and`, `or`, `not`) e relacionais.

- `05_Resolvendo_Dizimas.py`  
  Um problema prático envolvendo cálculos (possível manipulação de floats e formatação).

- `06_Captura.py`  
  Coleta de entrada do usuário via `input()` e uso dessa entrada no programa.

- `07_Conversao_de_Valores.py`  
  Conversões de tipos (`int`, `float`, `str`) e tratamento básico de erros.

- `08_If_Else.py`  
  Estruturas condicionais básicas `if / else`.

- `09_And_Or_If.py`  
  Combinações de condições com `and`/`or` em blocos `if`.

- `10_Or_If_Else.py`  
  Variações de estruturas condicionais com múltiplos ramos.

- `11_Estrutura_de_Repeticao.py`  
  Laços de repetição (`for`, `while`) e exemplos práticos.

Pré-requisitos
--------------
- Python 3.x (os exemplos foram preparados com compatibilidade para Python 3.6 — instalador em `Softwares/python-3.6.4-amd64.exe`).
- Editor de texto/IDE (recomendado: VS Code — instalador em `Softwares/VSCodeUserSetup-x64-1.66.2.exe`).

Como executar os exemplos
------------------------
Abra um terminal (bash) no diretório do repositório e execute os scripts dentro de `Secao_01_Python_para_Iniciantes/Python_Code`. Exemplos:

```bash
cd Secao_01_Python_para_Iniciantes/Python_Code
python 01_Print.py
# ou, se seu sistema requer:
# python3 01_Print.py
```

Observações:
- Alguns scripts solicitam entrada do usuário (por exemplo, `06_Captura.py`).
- Se o seu comando para Python for `python3`, substitua quando necessário.
